# 🛠️ AntiDoot v1.0

**AntiDoot** — многофункциональная утилита для диагностики, восстановления и управления Windows.

Программа объединяет большое количество системных инструментов в одном удобном интерфейсе и помогает работать как с обычной Windows, так и со сложными сценариями восстановления.

> ⚠️ **Важно:** AntiDoot содержит инструменты, которые могут изменять системные настройки, файлы и компоненты Windows. Используйте их внимательно и на свой страх и риск.

# ⚡ Возможности

AntiDoot объединяет системные инструменты Windows в одном приложении, позволяя быстро получить доступ к функциям, для которых обычно приходится использовать множество отдельных системных средств.

### 📝 Реестр

Работа с реестром Windows:

* просмотр разделов и параметров;
* изменение системных параметров;
* быстрый доступ к необходимым веткам;
* инструменты для восстановления настроек;
* работа с системными конфигурациями.

### 🚀 Автозагрузка

Управление компонентами, которые запускаются вместе с Windows:

* просмотр элементов автозагрузки;
* управление записями;
* различные источники автозапуска;
* анализ подозрительных элементов;
* быстрый доступ к параметрам автозагрузки.

### ⚙️ Процессы

Работа с запущенными процессами:

* просмотр процессов;
* управление процессами;
* получение информации о запущенных компонентах;
* дополнительные системные операции.

### 🔧 Службы

Управление службами Windows:

* просмотр служб;
* запуск и остановка;
* управление состоянием;
* работа с системными службами.

### 🔓 Ограничения

Инструменты для поиска и управления системными ограничениями Windows.

AntiDoot позволяет работать с параметрами, которые могут ограничивать запуск программ, изменять поведение системы или блокировать отдельные функции.

### 💿 WinRE

Работа со средой восстановления Windows.

AntiDoot может использоваться в ситуациях, когда Windows работает нестабильно или не может нормально загрузиться, предоставляя доступ к необходимым инструментам восстановления.

### 📁 Файловый менеджер

Встроенные инструменты для работы с файлами и папками:

* навигация по файловой системе;
* операции с файлами;
* работа с системными файлами;
* дополнительные файловые операции.

### 📦 Архивы

Работа с архивами непосредственно из интерфейса AntiDoot.

### 🛡️ Безопасность

Инструменты для диагностики и работы с компонентами безопасности Windows:

* анализ системных компонентов;
* работа с системными средствами;
* поиск проблемных элементов;
* инструменты восстановления.

### 🔍 MRT

Быстрый доступ к Microsoft Windows Malicious Software Removal Tool и связанным функциям диагностики системы.

### 🎮 Развлечения

Дополнительный раздел AntiDoot с развлекательными возможностями, который не связан непосредственно с восстановлением Windows.

### ⚙️ Настройки

Настройка поведения и интерфейса AntiDoot.

# 🛠️ Восстановление Windows

Одна из основных задач AntiDoot — помочь пользователю получить быстрый доступ к инструментам диагностики и восстановления Windows.

В зависимости от ситуации программа может использоваться для:

* диагностики системных проблем;
* восстановления системных компонентов;
* работы с реестром;
* управления автозагрузкой;
* управления службами;
* работы с процессами;
* доступа к WinRE;
* работы с системными файлами;
* восстановления отдельных параметров Windows.

> Некоторые операции могут существенно изменить систему. Перед выполнением критических действий рекомендуется создать резервную копию важных данных.

# 💿 Работа в WinRE

AntiDoot может использоваться в среде восстановления Windows для работы с системой в ситуациях, когда обычная загрузка Windows невозможна или ограничена.

WinRE предоставляет дополнительные возможности для диагностики и восстановления операционной системы.
